# Dipanshi Gupta — Personal Portfolio

Personal portfolio and engineering case studies showcasing work at the intersection of **Applied AI/ML**, **Full-Stack Systems**, and **Product Design (UI/UX)**.

---

## 🛠️ Core Technology Stack

* **Framework:** Next.js (App Router), React, TypeScript
* **Styling & Design System:** Tailwind CSS, CSS Custom Properties (Obsidian Dark & Warm-Neutral Light)
* **Typography:** Geist Sans (Headings & Body), Geist Mono (Technical metadata & pipeline metrics)
* **Backend & Systems Focus:** Python, FastAPI, PostgreSQL, SQLAlchemy, Docker
* **AI & Retrieval:** Hybrid Search (Dense Vector + BM25), Qdrant, Gemini API, PyMuPDF

---

## 📂 Featured Case Studies

1. **ManakSetu (Flagship)**: AI-Powered Indian Standards & Procurement Intelligence Platform utilizing hybrid semantic retrieval, multi-signal ranking, and evidence-grounded verification.
2. **AgriVision AI**: Computer vision pipeline for agricultural crop disease classification and containerized inference.
3. **Interview Tracker Pro**: Production-grade job application management system with relational data persistence and JWT security.
4. **Career Adviser**: Structured LLM career path advisory application built with Next.js, shadcn/ui, and Pydantic validation.

---

## 🚀 Development & Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
